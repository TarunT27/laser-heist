## Findings and iteration history

1. [P1, resolved] Old shoes were essentially rectangular blocks, oversized at the toe and instep. Replaced both with curved, subdivided uppers, tapered heel/waist, rounded toe, thin layered soles and crossed laces. Full-body comparison shows a slimmer shoe silhouette. The focused view confirms distinct upper/sole construction.
2. [P1, resolved] Movement changed the character's direction while leaving the camera looking elsewhere. The camera now smoothly trails actual character heading. Movement uses a stable input basis while a key is held, preventing the rotating camera from making the character circle. Mouse/touch orbit takes priority for 900 ms after a drag.
3. [P2, resolved] A rigid ankle collar and polygon-cut trouser hem produced a poor ankle join in the close-up. Added foot/calf weight blending to the shoe upper and collar and a planar cut to the trouser boundary. Re-exported and revalidated all six animations.
4. [P2, resolved] The studio's neutral-action selector could match CrouchIdle when looking for Idle. It now selects the exact Idle suffix. This affected the source preview selection; runtime animation names remain distinct.

## Required fidelity surfaces

- Typography: gameplay labels, timer and prompts remain readable at the tested viewport. The reference's compact timer is intentionally expanded into mission/crew UI for the cooperative game. No font changes in this revision.
- Spacing and layout: the controlled character remains central with the path ahead visible after turning; HUD controls remain on screen. The narrow viewport uses the existing touch layout. No layout redesign was part of this revision.
- Colors and tokens: charcoal shoes match the crew outfit; slightly lighter trim separates soles and laces. Museum ivory/brass/glass and mint/gold crew UI are preserved.
- Image quality: actual animated GLB geometry is loaded in the game. The revised shoes are not a raster overlay. No bare toes or box boots remain. The concept's richer reflections, sunset and environment detail are not reproduced at the same fidelity; those remain broader environment-art work outside this focused revision.
- Copy and content: field guide and desktop hints now state WASD/arrow movement and automatic camera follow. Roles, contract objectives, and fictional payout labels remain intact.

## Functional verification

- `npm run check`: typecheck, 20 tests, production build passed. Includes a regression proving held sideways movement does not spiral as camera yaw converges.
- `npm run validate:assets`: passed against the final 1,558,556-byte GLB. All mesh attributes finite; Idle, Walk, Run, Crouch, CrouchIdle and Interact present; actual skinned motion sampled; crouching lowers the model substantially.
- In browser: right and left turns, forward movement and sprint; tactical route through the crouched service vent; override, diamond pickup, and crew extraction. Practice ended with $10,830 shared take, two detections and 00:11 remaining.
- After final asset rebuild: reloaded, entered practice, repeated arrow movement and inspected the following camera and footwear. No new browser warnings/errors after the final reload. An earlier failed fetch occurred before restarting the local server and is not present after restart/reload.
- Independent read-only camera review: no blocking findings.
